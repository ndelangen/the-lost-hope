# Beast portrait mappings 01

This stage adds 50 printing-specific portrait mappings across 27 Beast forms on catalog `10c796c`. SRD 5.1 and SRD 5.2.1 each receive 25 mappings. All 27 portrait files retain the original bytes and recorded credits. The bundle references their established runtime paths. [Roster](roster.tsv) · [Portrait index additions](portrait-index-preview.json) · [Existing asset paths and hashes](existing-assets.json)

The selected SRD versions previously used fallback images from other printings. They now open on their mapped parchment portraits. The Library’s default printing, browse thumbnail, and existing publisher artwork and credits in the source printings remain unchanged. I deferred the profiles with their own published gallery defaults in this pass.

I checked search and printing switches in a disposable Library copy. The SRD Axe Beak loaded its mapped portrait, and the 2014 *Monster Manual* printing loaded the same credited illustration as before. Both Ape SRD printings loaded the same square portrait. The browser console was clear. I checked all 50 portrait keys and source hashes and compared the other printing profiles with the baseline. The primary checkout and R2 were untouched.
