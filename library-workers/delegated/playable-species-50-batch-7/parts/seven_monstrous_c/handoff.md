# Monstrous Races player conversions

Four player profiles, linked NPCs and square portraits are staged here. The profiles use Tyler Kamstra's DMs Guild supplement for the 2014 fifth edition. I checked the printed folios in the v2 reproduction, whose pagination differs from the roster's initial copy. [DMs Guild publication](https://www.dmsguild.com/product/230312/Monstrous-Races) · [V2 text]()

| Profile | V2 printed folio | Checked build |
| --- | --- | --- |
| Bulette | 27 | Marl, Barbarian 1. AC 15, HP 13, bite +4, leap save DC 12. |
| Cambion | 29 | Ilyra Vell, Champion Fighter 3. AC 14, HP 25, rapier +5, fire bolt +3, charm save DC 11. |
| Carrion Crawler | 30 | Silt Sifter, Rogue 1. AC 13, HP 11, bite and tentacles +4, tentacle save DC 13. |
| Chimera | 32 | Latch, Barbarian 1. AC 16, HP 14, unarmed strike +5, blue head lightning save DC 12. |

Marl uses the v2 trait block's 30-ft. burrow speed and follows normal jumping distance. The commentary mentions Standing Leap, which the v2 trait block omits. Outlander supplies Common. For Deadly Leap, the attack gates the save and damage applies once. The build keeps both creatures in the landing square when the result leaves the target there. The printed heading gives the land shark alias. [V2 text]() · [2014 movement rules](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/adventuring)

Silt Sifter uses the conversion's finesse unarmed strike rule for Sneak Attack. An eligible tentacle strike deals the bonus as poison. Latch illustrates the blue head. The whole set of printed Dragonborn ancestry breath choices stays in the single Chimera profile. [2014 class rules](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/classes) · [2014 ancestry table](https://www.dndbeyond.com/sources/dnd/basic-rules-2014/races)
