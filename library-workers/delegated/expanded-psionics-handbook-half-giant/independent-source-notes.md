# Independent checks

The source review confirmed that Powerful Build applies the advantageous larger size modifier to opposed checks, helps determine whether a size-based special attack affects the Half-Giant, and allows larger weapons. Space and reach use actual size. The trait stacks with true size changes. The 2008 Wizards FAQ confirms the scope. [Playable chapter]() · [Wizards FAQ, p. 2]()

The published warrior's Stomp uses Reflex DC 10 at manifester level 1 and Charisma 8. The 2006 errata leaves that rule intact and sets the cost of Expansion's longer duration to 2 extra PP. Anet's manifester level 1 permits only the one-round base form. The printed Half-Giant illustration on p. 201 is by Jeremy Jarvis. [Stomp]() · [Sample warrior]() · [Errata]()

The catalog review checked both builds' attack, grapple, save, and skill totals. It verified that Expansion ends before Anet's next turn and that Maenad and Half-Giant apply in either order in temporary files.
