# Proposed playable profiles, batch 8

50 claims for ownership review before dispatch. Every row gives the canonical name, aliases, exact publication, rules edition, and printed location. The roster uses Tyler Kamstra’s player conversions for the 2014 fifth-edition rules. Existing same-name encounter stat blocks keep their own scope.

Compared canonical names with the seven prior staged rosters and the committed catalog at `49079cd`. 2 names have no exact catalog entry and 48 have only non-player entries.
