# Gloaming

This batch adds the playable Gloaming from the October 2003 *Underdark* to the D&D 3.5 DM Library catalog. It includes Iskra Sablewing and Kes Hollowstep as original encounters and uses Iskra’s plain-parchment portrait for the 2003 profile.

The [rules patch](rules.patch) adds the catalog row, species profile, and NPC builds. The [portrait index preview](portrait-index-preview.json) points to the [square original](portraits/gloaming-draft.png). The [comparison](portrait-comparison.jpg) shows Iskra beside the approved Big Linda portrait.

In a temporary copy of `db7b24377a6a940dead7e12772785cdc902e152c`, search found Gloaming by name, Portal Sensitive, Luminescence, and both NPC roles. Both catalog commands returned the two complete builds. The 2003 profile resolved the staged portrait by hash and used it as the list thumbnail. The patch also applied after the preceding staged batches. See the [verification results](verification.json).
