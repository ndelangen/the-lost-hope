# Four 4e playable profiles

| Species | Printed source | Linked NPC |
|---|---|---|
| Drow | Monster Manual p. 276 | Sera Veld, passage scout |
| Bugbear | Monster Manual p. 276 | Rusk Sedge, ferry lookout |
| Hobgoblin | Monster Manual p. 278 | Varek Fordwatch, shield officer |
| Gnome | Player’s Handbook 2 pp. 10–11 | Tovin Reedwhistle, decoy guide |

The Monster Manual appendix asks for DM permission to use its racial profiles for PCs. The Gnome profile is from the player chapter of Player’s Handbook 2. The four original sample NPCs use level-one player character math. Direct book links, printed pages, and the source scan hashes are in `source-evidence.json`.

Each portrait is an original 1254 × 1254 ImageGen PNG. The portrait comparison puts Big Linda first, followed by the four profiles in table order. The separate thumbnail strip shows the same subjects at 96 × 96. I reviewed all four at full size and in the strip for subject clarity, plain parchment, and full-body framing. Tovin’s walking stick is part of his traveling kit. His build uses a wand for spell attacks.

The JSON payloads and portrait files are ready for the parent’s aggregate staging and temporary-copy checks.
