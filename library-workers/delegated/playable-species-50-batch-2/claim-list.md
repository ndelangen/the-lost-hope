# Approved playable species roster

The overlap review cleared these 50 claims before dispatch. Each covers one playable publication, a linked NPC, and an original portrait. The source handoffs record the verified printing and page numbers.

Compared the live DM Library at `c8e7384`, all 50 entries from the first batch, and the existing staged playable handoffs. The first batch and staged playable handoffs have no same-name claim in this list. An existing monster with the same name stays in the primary worker’s scope.

Every portrait brief uses Big Linda’s light warm parchment, a full-body isolated subject, muted naturalistic paint, and a faint contact shadow. The table records the original briefs.

## Catalog comparison

- 4 have an exact species row and still need local rules and a linked NPC.
- 12 have playable profiles in other publications.
- 24 appear only as monsters or beasts at the same name.
- 10 have no exact-name catalog row.

Coverage means an exact canonical name, publication, and edition. Alternate editions and setting lineages are called out in the table. Source links establish the intended printing. Some are publisher previews or indexes; the author still needs to verify the full printed player traits before writing the build.

Use the published monster-class progression for *Savage Species*, including the level where the featured ability unlocks. D&D 4e *Monster Manual* entries use its player racial-traits section. Neither group claims standalone monster stat blocks.
