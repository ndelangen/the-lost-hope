# Playable species batch 2

This batch stages 50 playable species, 50 linked NPC builds, and 50 original portraits. It adds 46 species records and supplies rules for 4 existing records. Each addition identifies its exact source and edition. Some names already have profiles in other editions.

[Catalog patch](rules.patch) · [Source and ownership manifest](manifest.json) · [Portrait index preview](portrait-index-preview.json) · [Approved roster](claim-list.md)

The patch is based on catalog commit `62ea1fb`. It covers species entries, local rules, and NPCs tied to those profiles. The portrait preview names the destination keys. The manifest and individual handoffs locate the staged raster originals.

## Review

Authors checked the original rules, NPC mechanics, and portraits by hand. Separate spot reviews covered ownership, publication boundaries, representative rules, and encounter math. Catalog search, runtime portrait loading, and automated tests are deferred. No changes were made to the primary checkout or R2.
