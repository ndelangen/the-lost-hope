# Playable species batch 3

This batch stages 50 playable species, 50 linked NPC builds, and 50 original portraits. It adds 43 species records and supplies rules for 7 existing records. Each addition identifies its exact source and edition. Some names already have profiles in other editions.

[Catalog patch](rules.patch) · [Source and ownership manifest](manifest.json) · [Portrait index preview](portrait-index-preview.json) · [Approved roster](claim-list.md)

The patch is based on catalog commit `d2bd3ab`. It covers species entries, local rules, and NPCs tied to those profiles. The portrait preview names the destination keys. The manifest and individual handoffs locate the staged raster originals.
