# Proposed playable species roster, batch 3

50 claims for review before dispatch. Each covers one playable rules profile, one linked original NPC, and one square plain-parchment portrait.

Compared exact publication and edition keys against catalog commit `62ea1fb`. Compared names and named variants against the two 50-entry batches. Monster entries with the same name and other playable printings stay outside these claims.

[Machine-readable claims](claims.tsv) · [Batch 1 manifest](../playable-species-50/manifest.json) · [Batch 2 manifest](../playable-species-50-batch-2/manifest.json)

The locators identify the source for each claim. The NPC and portrait columns are briefs. Confirm exact rule text and level prerequisites before building an example.

## Catalog coverage

- 22 have a same-name non-player entry.
- 13 have a species entry in another printing.
- 7 have exact species metadata and need local rules.
- 8 have no exact-name entry in the catalog.

## Shared boundaries

- Group each elemental progression under one species across its printed sizes. Griffon is a player monster class in the appendix. Use the printed tier even when its movement, size or equipment differs from the standalone monster.
- D&D 4e entries use the cited printing. Record separately any official errata applied to the NPC. The Monster Manual describes Goblin and Orc as player options with DM permission.
- Grim Hollow uses the revised 2025 guide, which credits SRD 5.2.1. The existing catalog edition key is Fifth edition compatible. Keep base traits separate from the traditional package.
- Across all portraits, use the approved Big Linda framing and plain warm parchment. Follow the exact species anatomy for each printing.
