# Five Savage Species monster classes

| Playable profile | Original NPC | Class level / HD / CR | Player rules |
| --- | --- | --- | --- |
| Fire Elemental | Vell, kiln brazier tender | 2 / 2 / 1 | [p. 167, Table A–16]() |
| Fire Giant | Dorran Emberkeel, forge escort | 6 / 5 / 3 | [pp. 167–168, Table A–17]() |
| Flesh Golem | Sedge, storehouse sentinel | 3 / 3 / 2 | [pp. 169–170, Table A–19]() |
| Frost Giant | Yrsa Paleledge, high pass escort | 11 / 8 / 5 | [pp. 170–171, Table A–20]() |
| Ghaele | Lethiren, witness courier | 7 / 6 / 4 | [pp. 171–173, Table A–21]() |

Vell uses the first tier with Burn. Dorran is Medium and catches thrown rocks. Yrsa uses the first Large tier and the 60-ft. rock increment. Sedge uses the class's spell resistance and construct healing exception. Lethiren uses the first tier with the incorporeal globe and takes Light Armor Proficiency for the chain shirt shown in the portrait. The build uses the five listed domains as additions to the normal cleric spell list and omits domain powers and extra domain slots.

I checked the class tiers, AC, saves, damage and use limits by hand. The portraits are 1254-pixel square originals generated with the built-in ImageGen tool.
