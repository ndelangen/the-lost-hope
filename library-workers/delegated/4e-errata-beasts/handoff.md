# Fourth-edition errata beasts

The patch turns two source-lookup entries into combat summaries using their fourth-edition stat blocks and Wizards' August 2012 rules update.

- **Ambush Vine** is a Level 16 Elite Controller worth 2,800 XP. The first printing gives 1,400 XP. The summary includes both ways the vine spawns shoots and the shoot's separate minion rules. [Monster Manual 2, pp. 204–205]() · [Collected rules update, p. 82](https://media.wizards.com/2014/downloads/dnd/4ECollectedErrataFAQ.zip)
- **Pseudodragon** is a Small Level 3 Lurker worth 150 XP. The update changes the earlier Tiny size, and the checked Deluxe printing already shows Small. Its profile includes the recharge rolls for Sting and the movement condition on Invisibility. [Monster Manual Deluxe, printed pp. 90–92]() · [Collected rules update, p. 77](https://media.wizards.com/2014/downloads/dnd/4ECollectedErrataFAQ.zip)
