# Giant Fly in Black Flag

The Ebony Fly entry in both Kobold Press reference documents has a Giant Fly stat block in the magic items chapter. The rules match across the two printings. The patch adds two Black Flag publication versions to the existing Giant Fly entry. [v0.2, pp. 97–98]() · [v1.0, pp. 105–106]()

The patch includes the figurine's activation, commands, mount duration, reversion, and two-day wait. The creature block gives no challenge rating, attacks, or natural habitat. Its Perception, Stealth, and ability modifiers are in the table notes. The two empty columns at the end of each TSV row are required by the catalog. The exact locations, hashes, and licenses are in the source evidence. [Patch](rules.patch) · [Source evidence](source-evidence.json) · [Independent check](independent-source-notes.md)

Both versions reuse the same plain parchment horsefly draft from the SRD batch. They have separate version-level portrait entries pointing to the same image. [Portrait](portraits/giant-fly-draft.png) · [Portrait index preview](portrait-index-preview.json) · [Portrait provenance](portrait-files.json)

I applied the patch in a temporary copy and loaded the library there. Searching for “giant fly”, “horsefly”, “ebony fly”, and “black flag giant fly” found the entry. I checked the rules rendered for each new version and matched both portrait hashes to the staged original. The four existing versions and the existing gallery matched the before snapshot.
