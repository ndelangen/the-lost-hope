# Mind Flayer

This batch adds the playable Mind Flayer to the 3.5 *Underdark* catalog using the *Monster Manual* character rules. Ilyth Voss and Sael Nethrix are original NPCs. Ilyth’s plain-parchment portrait represents the species profile.

The [rules patch](rules.patch) adds the species and both encounters. The [portrait index preview](portrait-index-preview.json) identifies the [square original](portraits/mind-flayer-draft.png). The [comparison](portrait-comparison.jpg) shows Ilyth beside Big Linda.

In a temporary copy, search found the species by name, Mind Blast, telepathy, and both NPC roles. The portrait loaded for the 2003 profile and as its list thumbnail. The existing monster entry, including its versions and portraits, matched the baseline. [Verification](verification.json)
