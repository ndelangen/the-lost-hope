# Humblewood Humblefolk

Added local player rules for Cervan, Hedge, Jerbeen, Mapach, and Vulpin. The records use the existing Humblewood Campaign Setting publication and Fifth edition compatible catalog label. The rules come from Hit Point Press's 2019 edition, digital v1.04. [Publisher listing](https://hitpointpress.itch.io/humblewood) · [Printed player entries, pp. 22–31]()

Six original classed NPCs use the player profiles and 2014 class rules. Bracken Mossbell and Hollis Shadebuck cover Grove and Pronghorn Cervan. The player Surge of Vigor needs an attack that deals **more than** half of current HP. The printed Cervan Priest uses a different threshold on p. 193. The five original ImageGen portraits use Big Linda's plain parchment. I reviewed the complete silhouettes and the 96 px thumbnails by eye. Catalog integration and runtime checks are pending.
