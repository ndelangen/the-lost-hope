# Flee, Mortals! public preview beasts

The patch adds both missing beast profiles from the MCDM public preview. The Swarm of Skitterlings is a CR 2 Soldier worth 450 XP. The War Spider is a CR 3 Brute worth 700 XP. Both use 2014 fifth edition rules. [MCDM public preview, p. 9]()

The profiles use the printed preview rules for Claws, Web Spray, Trample, rider capacity and the spider's death trigger. The later *Where Evil Lives* rules differ. The full commercial *Flee, Mortals!* blocks could not be verified from the signed-out D&D Beyond links. [Independent source notes](independent-source-notes.md)

Desert, forest and underground tags reflect the preview's goblin encounter settings. The creature descriptions explain how goblins use both beasts and give their appearance. The later Jagged Edge Hideaway confirms underground encounters for each. [MCDM public preview, p. 5]() · [Where Evil Lives preview, pp. 10–11]()

Both entries already use approved square parchment portraits from batch 08. The existing portraits and credited publisher art stay in the same gallery order. [Portrait comparison](portrait-comparison.jpg) · [Portrait hashes](portrait-reuse.json)
