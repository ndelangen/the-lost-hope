# Humblewood Campaign Setting beasts

Five existing beast records now have rules summaries staged from the v1.04 printing. I checked the blocks in the original Appendix A page scans and checked the page numbers against the text. The rules patch only adds profiles to the current catalog. Each challenge rating below is printed in that creature's block. The Forest Prowler can make its bonus claw attack against the pounce target without a stated prone requirement. The Mountain Lion's bonus bite requires a prone target, and Call Avalanche requires mountainous terrain. The Wakewyrm retains the printed 11 (3d6) swallowing damage and the 18-damage threshold for its save to avoid regurgitating swallowed creatures.

I used built-in ImageGen for the four new square portraits. The plain parchment style comes from the Giant Fly draft, with creature details drawn from the source illustrations. The existing swarm portrait retains its original file and hash.
