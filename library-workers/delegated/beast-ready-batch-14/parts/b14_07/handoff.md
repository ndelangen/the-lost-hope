# Batch 14 · Rise of Tiamat supplement

Four Beast records follow Wizards' November 5, 2014 online supplement v0.2. The Giant Octopus is on p. 16, Polar Bear on p. 22, Warhorse on p. 26, and Wolf on p. 27. Each folio matches the page number. [Wizards v0.2 supplement]()

The supplement shows the Warhorse's Hooves at +4 to hit. The 2014 Monster Manual errata changes the Warhorse in that book to +6. This entry uses the supplement's value. [Monster Manual errata]()

All four portraits reuse earlier art on plain muted parchment. Each matches its roster checksum and depicted subject. The supplement gives no habitat tags for these blocks, so the terrain labels are editorial.
