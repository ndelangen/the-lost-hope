# Chitine

This batch adds the playable Chitine from the October 2003 *Underdark*. Qid Lowweb and Awa Spinner are original NPCs, and Qid’s four-armed portrait represents the 3.5 species.

The [rules patch](rules.patch) adds the species and both encounter builds. The [portrait index preview](portrait-index-preview.json) identifies the [square original](portraits/chitine-draft.png). The [style comparison](portrait-comparison.jpg) shows Qid beside Big Linda.

In a temporary copy, search found the species by name, Multiweapon Fighting, sunlight sensitivity, and both NPC roles. The portrait loaded for the 2003 profile and as the species thumbnail. The existing monster versions and portrait data matched the baseline. [Verification](verification.json)
