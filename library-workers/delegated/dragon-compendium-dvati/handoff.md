# Dvati for D&D 3.5

The October 2005 *Dragon Compendium, Volume I* presents the Dvati as one character in two bodies. Roll each Hit Die once, split the die result, and add the full Constitution modifier to each twin. Track damage and healing separately. Spell slots and limited class uses belong to the pair. [Original 3.5 rules, pp. 15–17]() · [Species rules](book-species.json)

- **Aven and Iven Threadwell**, Bard 2, have 9 HP each and one shared 1st-level slot. *Expeditious retreat* benefits both on the same plane. *Cure light wounds* heals one touched target.
- **Mara and Sera Reedbank**, Fighter 1, have 7 HP each. Pair Link raises their flank bonus to +3. Both spend a move action on Echo Attack, which can add a further +1 to attacks or AC against the target on a failed save.

The encounter cards use one initiative roll per pair as a table ruling. Place both twins on the map and track their HP separately. Each pair is one catalog encounter.
