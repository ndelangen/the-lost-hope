# Playable species batch 4

This batch stages 50 playable profiles, 50 linked NPC builds, and 50 original portraits. All 50 are new publication and edition records. Each addition identifies its exact source and edition. 18 named lineages sit under their canonical species. The manifest records one owner for each species group.

[Catalog patch](rules.patch) · [Source and ownership manifest](manifest.json) · [Portrait index preview](portrait-index-preview.json) · [Approved roster](claim-list.md)

The patch is based on catalog commit `758eb9e`. It covers species entries, local rules, and NPCs tied to those profiles. The portrait preview names the destination keys. The manifest and individual handoffs locate the staged raster originals.


Skullcrusher Ogre uses the Ogre entry in [batch 3](../playable-species-50-batch-3/handoff.md). Integrate that batch before applying this profile.
