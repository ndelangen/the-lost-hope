# Troglodyte

This batch adds the playable Troglodyte to the 3.5 *Underdark* catalog using the *Monster Manual* character rules. Sethrik Chalkscale and Vess Siltcrest are original NPCs. Sethrik’s plain-parchment portrait represents the species profile.

The [rules patch](rules.patch) adds the species and both encounters. The [portrait index preview](portrait-index-preview.json) identifies the [square original](portraits/troglodyte-draft.png). The [comparison](portrait-comparison.jpg) shows Sethrik beside Big Linda.

In a temporary copy, search found the species by name, Stench, Multiattack, and both NPC roles. The portrait loaded for the 2003 profile and as its list thumbnail. The existing monster entry, including its versions and portraits, matched the baseline. [Verification](verification.json)
