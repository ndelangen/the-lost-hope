# Batch 13, part b13_02

Staged six Frostmaiden Beast scopes from the August 2020 first printing. Kingsport has his own block on p. 243. Fox, Hare, and Giant Walrus use Appendix C. The two chimeric forms use the p. 246 table and the 2014 Monster Manual base blocks. The first printing gives Hare 0 XP. The public D&D Beyond creature links redirect to the book’s Marketplace page. [Wizards source index](https://www.dndbeyond.com/sources/dnd/idrotf)

All six portraits were generated individually with built-in ImageGen and checked at thumbnail size. Each image shows one creature on muted tan parchment, with the full body inside the square. The Chimeric Rat has gills and iridescent scales. The Chimeric Weasel has a luminous eye. Kingsport is an eyeless albino penguin with a leather harness. The Giant Walrus portrait also depicts the same anatomy described for Walrus.
