# The Old Margreve beasts

This patch covers the 15 remaining beast source lookups in the Tales of the Valiant printing of *The Old Margreve*. The publisher-authored book text identifies the conversion team and lists ISBN 978-1-964506-07-4, which matches the publisher's sell sheet. The mirror interleaves text columns. The page references use the book's printed footers. [Book text, Appendix pp. 215–241](https://www.scribd.com/document/1021928968/The-Old-Margeve-2025-03-10-Yxvulx) · [Publisher listing](https://koboldpress.com/kpstore/product/the-old-margreve/) · [ISBN evidence]()

The nine CR 1/4 profiles use the book's fraction. The publisher's index displays these as 0.3 and supplies the terrain tags for all 15. The Margreve Hound's trait is titled *Heightened Hearing and Smell*, but the printed rule grants Perception 18 for smell alone. The profiles follow the rule text. The publisher's errata for this book lists no changes to these beast stat blocks. [Terrain index](https://koboldpress.com/tools/search-tov-kobold-press-monsters/) · [Published errata](https://koboldpress.com/errata/#:~:text=The%20Old%20Margreve)

The Alligator has a new portrait. The Strossen Bat draft adds the white eye stripe described in the book. Thirteen other entries reuse their existing isolated portraits, some with warmer parchment than the new drafts. The previous Strossen Bat art remains available as a source file.
