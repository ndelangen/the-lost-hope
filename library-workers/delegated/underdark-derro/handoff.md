# Derro

This batch adds the playable Derro from the 2003 *Underdark*. It uses that book’s ECL 4 advancement and draws on the core rules for racial traits. Dorr Palevein and Mira Chalkwick are original NPCs. Dorr’s plain-parchment portrait represents the species profile.

The [rules patch](rules.patch) adds the species and both encounters. The [portrait index preview](portrait-index-preview.json) identifies the [square original](portraits/derro-draft.png). The [comparison](portrait-comparison.jpg) shows Dorr beside Big Linda.

In a temporary copy, search found Derro by name, sunlight vulnerability, *ghost sound*, and both NPC roles. The portrait loaded for the 2003 profile and as its list thumbnail. The existing monster entry, including its versions and portraits, matched the baseline. [Verification](verification.json)
