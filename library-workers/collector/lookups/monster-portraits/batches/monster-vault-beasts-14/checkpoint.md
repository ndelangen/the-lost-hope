# Monster Vault beasts, final batch

Giant Weasel, Dire Wolf, Hippocampus, and Orca have new 1254 × 1254 square parchment portraits. Hippocampus and Orca appear under two Black Flag publications, so each uses the same portrait and credited alternates in both galleries.

Chromium verified all four portraits and 13 credited alternate placements across six publication versions. The four originals and nine unique source files have checksum-verified external backups. All four uploaded originals match their R2 locks.

All 96 beast entries that cite Monster Vault have local artwork. This count includes entries with Monster Vault as a secondary source. Across the library, 166 beasts still lack artwork. All 5,932 monster entries have it.

The Revised v3.5 SRD has the largest remaining group, with 42 beasts missing artwork. The next queue contains Bat Swarm, Cheetah, Dire Ape, and Dire Badger.

All 887 tests, the production build, and the media gate passed. Local commit `a68d323` records the registry and R2 lock.
