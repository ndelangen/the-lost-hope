# The Sunken Pyramid portrait checkpoint

Sahuagin, Many-Faced; Sahuagin, Mystic; Skeleton, Sharkjaw; and Xok Utal have original 1254 × 1254 parchment portraits. The corrected portraits remove small duplicate corner figures. Xok Utal depicts a representative warrior. The Sharkjaw Skeleton gallery includes a miniature render by mz4250 and a Roll20 token preview by David North.

Chromium verified all four galleries and both alternates. The external backup holds four drafts, four corrected originals, and two source images. The corrected originals are synced to R2, and the media gate verified all 363 registered originals. All 887 tests and the production build passed.

Local commit `cf4f35b` records the four artwork registrations and lock hashes.
