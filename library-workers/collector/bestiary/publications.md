The five creatures in Monstrous Compendium Vol. 3 came from the [publisher’s release notes](https://www.dndbeyond.com/forums/d-d-beyond-general/release-issues-support/168084-monstrous-compendium-volume-three-minecraft). Challenge and creature type are blank where those notes supply only a name, except the Wolf of the Overworld is filed under beasts. All other rows in this table come from the [D&D Beyond monster index](https://www.dndbeyond.com/monsters).

The table counts online listings. The local 2014 Monster Manual audit adds a Rogue Modron entry for 497 total catalog records.

The index returns two versions each of Boggle, Darkling, Darkling Elder, Korred, Quickling, and Redcap under both Volo’s and Witchlight. The catalog uses the explicit Volo’s versions for Volo’s and leaves the Witchlight associations unresolved. The Monsters of the Multiverse versions retain their own records.
